Cybersecurity Essentials — Course Syllabus

This syllabus introduces key cybersecurity concepts, safe online behavior, and basic threat prevention.

  • Lesson 1: Introduction — get introduced to cybersecurity fundamentals, threat awareness, and secure online practices.
  • Lesson 2: Center for Internet Security — learn about CIS and how its security controls help protect systems and networks.
  • Lesson 3: Kali Linux installation — step-by-step Kali Linux installation and setup for security testing labs.
  • Lesson 4: Weaponizing Windows 1 — introductory techniques for weaponizing Windows in security testing labs.
  • Lesson 5: NGROK: Connecting Servers To Internet — learn how to use NGROK to securely connect local servers to the internet for testing and remote access.
  • Lesson 6: Kali Linux features and functions for ethical hacking 1 — explore the features and functions of Kali Linux for ethical hacking and penetration testing.
  • Lesson 7: Install Kali Linux on Windows — step-by-step guide to installing Kali Linux on Windows using WSL or virtualization.
  • Lesson 8: Web Servers VS Applications — understand the difference between web servers and web applications, and how they interact.
  • Lesson 9: Vulnerability Scanning with Acunetix — learn how to scan for web vulnerabilities using Acunetix and interpret the results.

Course outcomes

  • Understand core cybersecurity principles and why they matter.
  • Recognize common cyber threats like phishing, malware, and weak passwords.
  • Apply basic safe browsing, account protection, and data privacy habits.
  • Gain confidence in staying secure while working and learning online.

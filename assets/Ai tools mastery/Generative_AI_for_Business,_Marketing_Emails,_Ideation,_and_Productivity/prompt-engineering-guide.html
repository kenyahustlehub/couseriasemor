Prompt Engineering Guide

Learn how to write prompts that get accurate, useful, and creative responses from AI tools like ChatGPT.

Prompt Writing Steps

  1. State your objective clearly.
  2. Include context about the business, audience, and format.
  3. Ask for structure or examples if needed.
  4. Use role instructions: “Act as a copywriter”, “Act as a marketer”, etc.
  5. Refine with follow-up questions.

Example prompt

“Write a 5-sentence marketing email for a business coach launching an AI productivity workshop, using an energetic and professional tone.”

Common best practices

  • Use short, direct instructions.
  • Provide examples when the output needs a specific tone.
  • Ask for a revision if the first answer is too generic.

Midjourney Prompt Guide

Use these prompt patterns to generate sharp, on-brand visuals with Midjourney.

Prompt structure

  1. Start with the main subject or scene.
  2. Add style, mood, and color direction.
  3. Include the use case (social, ad, mood board).
  4. Finish with technical details like lighting or composition.

Example prompt

Modern business meeting with AI tools, warm lighting, futuristic workspace, professional branding, 4k

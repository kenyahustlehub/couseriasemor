Modern Web Development — Course Syllabus

This syllabus guides students through building responsive websites with HTML, CSS, JavaScript, and modern frameworks.

  • Lesson 1: VS Code in 100 Seconds — quick introduction to Visual Studio Code, the essential code editor for modern web development.
  • Lesson 2: What You'll Get in This Course — overview of course content, learning outcomes, and skills you'll master in Modern Web Development.
  • Lesson 3: How Does the Internet Actually Work — learn DNS, HTTP, servers, and client-server architecture fundamentals.
  • Lesson 4: How Do Websites Actually Work — understand how websites are built, hosted, and rendered by browsers.
  • Lesson 5: How to Get the Most Out of the Course — learn tips for staying engaged and getting the most value from this web development course.
  • Lesson 6: How to Get Help When You're Stuck — learn where to find help and use resources when you need support during web development.
  • Lesson 7: What is HTML — learn the basics of HTML and how it structures web pages for the browser.
  • Lesson 8: How to Download the Course Resources — learn how to download and organize the resources needed for course practice.
  • Lesson 9: HTML Heading Elements — learn how heading tags structure page content semantically.
  • Lesson 10: HTML Paragraph Elements — learn how to use paragraph tags and structure textual content semantically.
  • Lesson 11: Self-Closing Tags — understand self-closing tags in HTML and when to use them effectively.
  • Lesson 12: Project: Movie Ranking — build a small movie ranking project to apply HTML structure and basic interactivity.
  • Lesson 13: How to Ace this Course — tips and strategies to get the most from this course and succeed in projects and assessments.
  • Lesson 14: Why do we need CSS? — understand why CSS is essential for styling web pages and separating content from presentation.
  • Lesson 15: How to add CSS — learn how to add CSS to HTML pages using inline, internal, and external stylesheets.
  • Lesson 16: CSS Selectors — learn CSS selectors and how to target HTML elements for styling efficiently.
  • Lesson 17: Project: Colour Vocab Website — build a colour vocabulary website project to practice CSS and layout for visual design.
  • Lesson 18: Tip from Angela - Dealing with Distractions — practical tips on minimizing distractions and staying focused while learning web development.
  • Lesson 19: CSS Display — learn how CSS display values control layout behavior and how to use them for page structure.
  • Lesson 20: CSS Float — learn how CSS float works and how to use it to position elements on a page.
  • Lesson 21: Media Queries — learn how to use media queries to make responsive layouts that adapt to different screen sizes.
  • Lesson 22: Project: Web Design Agency Website — build a web design agency website project to practice responsive layouts and visual styling.
  • Lesson 23: Introduction to JavaScript — get introduced to JavaScript: variables, functions, and how scripts add interactivity to web pages.
  • Lesson 24: Backend Tools and Technologies — overview of backend tools and technologies and guidance on which to learn next.
  • Lesson 25: Advanced JavaScript Patterns — explore advanced JavaScript patterns, best practices, and techniques for more maintainable, modular code.
  • Lesson 26: JavaScript Alerts & Website Behavior — learn how to use alerts and add interactive behavior to web pages with event-driven scripting.
  • Lesson 27: JavaScript Data Types — understand JavaScript data types and how to use them for reliable, bug-resistant code.
  • Lesson 28: JavaScript Variables — learn how variables work and how to store, update, and use values in your web apps.
  • Lesson 29: JavaScript Variables Exercise Start — start the variables exercise and practice using variables in a real coding challenge.
  • Lesson 30: Naming and Naming Conventions for JavaScript Variables — learn how to name JavaScript variables clearly and consistently using naming conventions for cleaner code.
  • Lesson 31: String Concatenation — learn how to join strings in JavaScript and build dynamic text for your web applications.
  • Lesson 32: String Lengths and Character Count — learn how to get string length in JavaScript and retrieve the number of characters in text values.
  • Lesson 33: String Slicing and Extraction — discover how to extract parts of a string in JavaScript using slicing, substring, and related methods.
  • Lesson 34: Build a Drum Kit — build an interactive drum kit web app using JavaScript event listeners and sound playback.
  • Lesson 35: Adding Event Listeners to a Button — learn how to attach event listeners to buttons to handle clicks and other user interactions.
  • Lesson 36: Higher-Order Functions — understand higher-order functions and how to pass functions as arguments to other functions in JavaScript.
  • Lesson 37: Playing Sounds on a Website — learn how to play sound effects and music on a website using the Web Audio API and HTML5 audio.
  • Lesson 38: A Deeper Understanding of Javascript Objects — dive deeper into JavaScript objects, understanding their structure, methods, and how to work with them effectively.
  • Lesson 39: How to Use Switch Statements in Javascript — learn how to control program flow using switch statements for cleaner conditional logic.
  • Lesson 40: Objects, their Methods, and the Dot Notation — learn how to use object methods and dot notation to access and manipulate JavaScript object properties.

Course outcomes

  • Build responsive websites with HTML5, CSS3, and modern layout techniques.
  • Master JavaScript for interactive web applications.
  • Deploy projects to production using modern tools and workflows.
  • Work with popular frameworks and build systems for efficient development.
